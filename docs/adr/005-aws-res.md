# ADR 005: AWS Research and Engineering Studio (DESIGN-ONLY)

## Status
DESIGN-ONLY.

## Context
RES provides VDI, project workspaces, and identity-integrated portals for research users.

## Decision (target)
Adopt RES (or equivalent) for researcher-facing workspaces in production.

## Why not built
Licensing, cost, and scope exceed the sandbox test bed.

## Sandbox substitute
Login node SSH + optional NICE DCV TRY path + local YAML users + status portal (Task 22).
